# Android 客户端

本目录预留给 Android 客户端，目前尚未包含应用源码或可运行的 APK。

计划仅支持 Android 12 及以上的 ARM 架构设备（`arm64-v8a`、`armeabi-v7a`），以设备实际报告的 Android API 与 ABI 为准。华为 EMUI 与鸿蒙不等同；鸿蒙或卓易通运行环境可能有部分功能不支持或不生效，后续不考虑适配。兼容环境识别存在不确定性，不能运行 Android APK 的设备也无法安装此客户端。

计划在电量小于或等于 30% 时停止自动登录并退出，同时通过通知告知用户。透明窗口需要悬浮窗权限；通知若被用户或系统禁用，低电量提示将在下次打开应用时显示。

拟采用 Kotlin + Jetpack Compose，支持电信与移动两套认证流程，默认电信。实际手机门户参数、指定校园 Wi-Fi 的认证请求，以及 WebView 后台兜底能力需要验证后再实施。

Android 将使用独立的版本和更新配置，不复用仓库根目录的 Windows 更新清单。构建产物按工作目录约定放入仓库外的 `build/android/`，本机配置和签名密钥不提交到 Git。

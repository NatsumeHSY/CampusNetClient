# Android 客户端

Android 客户端面向 Android 12 及以上、`arm64-v8a` 或 `armeabi-v7a` 设备。项目使用 Kotlin 和 Jetpack Compose。当前提供电信、移动套餐选择及 HTTP 登录初版，仍需在实际校园网和 ARM 手机上验证。

## 登录

1. 连接校园 Wi-Fi，并打开客户端。
2. 选择电信或移动，输入校园网账号和密码。
3. 电信套餐还需要填写手机 Wi-Fi 网络详情中显示的 MAC 地址。
4. 保存设置后点击“登录”。客户端会在所选 Wi-Fi 网络上访问门户，并检查该 Wi-Fi 的外网连通状态。

默认选择电信。移动套餐仍在测试。电信流程沿用 eportal 字段和双重 URL 编码；移动流程读取 `goLoginForm`、表单字段和 Cookie，并将登录提交限制在门户页面的同源地址。若门户页面或参数变化，登录可能失败。

校园门户使用 HTTP，因此账号密码在 Wi-Fi 链路中未加密。请只在可信校园网络中使用。MAC 地址因 Android 设备及 Wi-Fi 隐私设置而异，应填写当前校园 Wi-Fi 详情中显示的地址；缺少有效 IP 或 MAC 时，电信登录会停止提交。

## 平台兼容性

仅支持 Android 12 及以上的 ARM 设备；不支持 x86 或 x86_64。鸿蒙设备不在支持范围内，后续不考虑适配。鸿蒙或卓易通兼容环境可能有部分功能不支持或不生效；环境识别可能无法覆盖所有设备。

## 当前限制

校园网登录流程尚未完成实机验证。自动重连、开机启动、前台服务、低电量自动退出、透明悬浮窗、WebView 兜底及 Android 自动更新仍未实现。Debug 签名版本只用于测试，不是正式发布版本。

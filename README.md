# 广航海校园网自动登录

CampusNetClient 为校园网提供自动认证和连接状态查看，包含 Windows 客户端与开发中的 Android 客户端。Windows 版使用 WinUI 3、C++ 和 Windows 服务；Android 版使用 Kotlin 与 Jetpack Compose。

## 客户端

- [Windows 客户端](desktop/README.md)：提供电信和移动套餐认证、服务管理、系统托盘和自动更新。移动套餐仍在测试。
- [Android 客户端](android/README.md)：支持 Android 12 及以上的 ARM 设备，目前提供 HTTP 登录初版，仍需在实际校园网和手机上验证。

鸿蒙设备不在支持范围内，后续不考虑适配。鸿蒙或卓易通兼容环境可能有部分功能不支持或不生效。

# Windows 客户端

CampusNetClient 是校园网自动登录客户端，采用 WinUI 3、C++、原生 Win32 启动器和 Windows 服务。客户端和更新器提供图形界面。

## 功能

- 支持电信套餐；移动套餐通过 Dr.COM BOSS HTTP 认证，仍在测试。
- 服务检查校园网状态并执行 HTTP 认证。按套餐流程验证登录结果后才报告成功。
- 状态页面显示服务连接状态、本机网络信息、外网地址和连通情况。
- 可启用客户端开机自启：用户登录 Windows 后，服务会在后台启动客户端。
- Windows 服务可在开机后运行并处理自动登录。服务安装、启动及管理操作需要管理员权限。
- 客户端使用托盘常驻：关闭窗口会隐藏到托盘；点击托盘图标可重新打开窗口，右键菜单可打开或退出客户端。退出客户端不会停止服务。重复手动打开会唤醒已有窗口。

## 使用方法

### 绿色版

绿色版目录包含启动器及完整运行文件：

```text
CampusNetClient-Release/
├── CampusNetLauncher.exe
└── bin/
    ├── CampusNetClient.exe
    ├── CampusNetService.exe
    ├── CampusNetUpdater.exe
    ├── version.json
    └── Windows App SDK 运行文件、资源和状态图片
```

解压完整目录后，双击 `CampusNetLauncher.exe`。在“登录凭据”卡片选择套餐并保存校园网账号和密码，再在“Windows 服务”卡片安装并启动服务。服务使用 Windows Credential Manager 保存凭据。

### MSI 版

运行 MSI 安装包并按 Windows Installer 提示完成安装。安装过程需要管理员授权；安装后 `CampusNetService` 会配置为随 Windows 启动。可通过 Windows“已安装的应用”卸载客户端。

### 套餐登录

默认套餐为电信。在“登录凭据”卡片中选择电信或移动，再保存设置。服务运行时会使用保存的凭据；移动套餐目前仍需在实际校园网络中验证。认证门户使用 HTTP，账号密码在校园网链路中未加密，请只在可信网络环境使用。


移动认证使用门户跳转中的网关参数建立会话，再向带 `JSESSIONID-BOSS-0` 的 `/webauth.do` 地址提交账号和密码，以外网探测返回 HTTP 204 确认成功。网关参数优先取实际跳转；未提供时使用 `wlanacname=hhxy`、`vlan=3017`，可在 `config.json` 中通过 `mobileAcName`、`mobileVlan` 调整。参考 [gh-campus-network](https://github.com/Li-Hikinghat/gh-campus-network)。

## 自动更新

客户端支持绿色版和 MSI 版。安装了 Windows 服务时，服务以 SYSTEM 身份启动并守护更新代理；代理等到有用户登录交互桌面后立即检查，随后每 10 分钟检查一次。没有安装服务时，管理员启动客户端会启动并守护同一更新代理。客户端首次显示时会要求代理立即检查，并在遮罩上等待结果，最长等待 40 秒。

更新代理从 HTTPS 清单获取版本和公告，下载对应资产后核验文件清单、大小和 SHA-256。版本号只要与清单不同就应用清单版本；本地文件校验不符时也会重新下载修复。发现更新后，原生 Win32 更新窗口显示版本差异、公告、下载进度和速度。

应用更新前会关闭客户端，并在已安装服务时停止服务。独立更新工作进程应用更新，完成后恢复原先安装的服务并重新启动客户端。绿色版会先校验并准备完整新目录；服务启动失败时恢复旧版本。MSI 版由 Windows Installer 应用。客户端重启需要管理员权限时，Windows 可能显示 UAC；取消重启不会撤销已安装的更新，可以之后手动打开客户端。Windows 服务设置为自动启动并配置持续失败重试；普通用户不能通过服务管理器停止或修改服务，本机管理员仍可更改。

SHA-256 用于检查下载内容是否与清单一致，不等同于发布者数字签名。

## 常见问题

- **登录状态未知或失败**：检查服务状态、当前联网网卡和校园网连接；公网地址暂时无法获取时，客户端不会将未知结果显示为外网已连通。
- **更新检查结果**：遮罩会显示检查结果和状态图标，短暂展示后自动关闭。没有新版本、超时、检查失败和发现新版本分别显示。

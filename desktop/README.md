# Windows 客户端

CampusNetClient 是校园网自动登录客户端，采用 WinUI 3、C++、原生 Win32 启动器和 Windows 服务。客户端和更新器提供图形界面。

## 功能

- 支持电信套餐；移动套餐通过门户表单认证，仍在测试。
- 服务检查校园网状态并执行 HTTP 认证。只有门户返回有效成功结果后才报告登录成功；HTTP 登录失败时可由 WebView2 兜底。
- 状态页面显示服务连接状态、本机网络信息、外网地址和连通情况。
- Windows 服务可在开机后运行并处理自动登录。服务安装、启动及管理操作需要管理员权限。
- 客户端使用托盘常驻：关闭窗口会隐藏到托盘；点击托盘图标可重新打开窗口，右键菜单可打开或退出客户端。退出客户端不会停止服务。重复手动打开会唤醒已有窗口。

## 使用方法

### 绿色版

绿色版目录包含启动器及完整运行文件：

```text
CampusNetClient-Release/
├── CampusNetLauncher.exe
└── bin/
    ├── CampusNetClient.exe
    ├── CampusNetService.exe
    ├── CampusNetUpdater.exe
    ├── version.json
    ├── WebView2Loader.dll
    └── Windows App SDK 运行文件、资源和状态图片
```

解压完整目录后，双击 `CampusNetLauncher.exe`。在“登录凭据”卡片选择套餐并保存校园网账号和密码，再在“Windows 服务”卡片安装并启动服务。服务使用 Windows Credential Manager 保存凭据。

### MSI 版

运行 MSI 安装包并按 Windows Installer 提示完成安装。安装过程需要管理员授权；安装后 `CampusNetService` 会配置为随 Windows 启动。可通过 Windows“已安装的应用”卸载客户端。

### 套餐登录

默认套餐为电信。在“登录凭据”卡片中选择电信或移动，再保存设置。服务运行时会使用保存的凭据；移动套餐目前仍需在实际校园网络中验证。认证门户使用 HTTP，账号密码在校园网链路中未加密，请只在可信网络环境使用。

如果 HTTP 认证不能完成，客户端可尝试 WebView2 浏览器兜底。此功能需要系统安装 Evergreen WebView2 Runtime，并且可能要求用户在前台完成门户交互。

## 自动更新

客户端支持绿色版和 MSI 版更新。更新器从可信 HTTPS 清单检查版本并下载对应版本，核验文件大小和 SHA-256 后应用更新。相同版本但文件校验不符时也会重新下载修复；清单指定的版本可能高于或低于当前版本。

Windows 服务可以在没有客户端窗口时检查和下载更新。存在交互式桌面时，原生更新窗口会显示版本变化、公告和下载进度；用户首次打开客户端时也会检查更新。更新期间窗口暂不可操作。

绿色版更新会先校验并准备完整新目录；新服务启动失败时会恢复旧版本。MSI 更新由 Windows Installer 应用。更新重启需要管理员权限时可能出现 UAC；取消重启不会撤销已经安装的更新，可以稍后手动打开客户端。

SHA-256 用于检查下载内容是否与清单一致，不等同于发布者数字签名。

## 常见问题

- **提示找不到 `WebView2Loader.dll`**：确认启动了完整绿色版目录中的启动器，且 `bin` 文件夹及运行文件完整。
- **WebView2 兜底没有出现**：确认安装 Evergreen WebView2 Runtime，并允许客户端在用户会话中打开窗口。
- **登录状态未知或失败**：检查服务状态、当前联网网卡和校园网连接；公网地址暂时无法获取时，客户端不会将未知结果显示为外网已连通。
- **更新检查结果**：遮罩会显示检查结果和状态图标，短暂展示后自动关闭。没有新版本、超时、检查失败和发现新版本分别显示。
